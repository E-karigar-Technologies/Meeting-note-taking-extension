# Meeting Note Taker

Record meetings with screen, system audio & microphone. Download recordings and get AI-powered transcriptions with meeting summaries.

## Features

* **Screen & Audio Recording:** Capture your screen along with system audio and your microphone.
* **Downloadable Recordings:** Save your meeting recordings locally.
* **AI-Powered Transcriptions:** Get transcriptions of your meetings.
* **Meeting Summaries:** Automatically generate summaries of your recorded meetings.

## Installation

1. Clone or download this repository.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click on **Load unpacked**.
5. Select the directory containing this extension (`meeting-note-taking`).

## Usage

1. Click the "Meeting Note Taker" extension icon in your Chrome toolbar.
2. Use the popup to start and stop your recordings and access other features.
